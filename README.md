# CadCraft in C++ (test version)

A test version of [CadCraft](https://getcadcraft.com) written in C++: the same apps, files and help as the
JavaScript CadCraft 0.5, rebuilt on one C++ codebase for the desktop and the browser (WebAssembly + WebGPU).
It is a test version; CadCraft itself is the JavaScript build.

Preview: https://cpp.getcadcraft.com (unlisted).

Status: work has started; see `docs/roadmap.md` once it lands. Agents: read [AGENTS.md](AGENTS.md).
